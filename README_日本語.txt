MIDI キーボード演奏ツール（Windows 64bit）
バージョン: 1.1 / 作成日: 2026-11-21

【はじめに】
MIDIファイルを読み、Virtual Piano形式のキーボード操作として演奏先へ送るツールです。
Roblox以外のWindowsアプリやブラウザーでも使用できます。
このフォルダーはローカル保存用です。

【起動方法】
1. MIDIKeyboardPlayer.exe をダブルクリックします。Pythonの別途インストールは不要です。
2. 演奏先のピアノアプリやWebピアノを開き、キーボード演奏を有効にします。
3. 「MIDIを選ぶ」で好きなMIDIを選びます。初期選択は samples/demo.mid です。
   以前の曲は「個人利用MIDI」フォルダーにあります。
4. 「入力先」は「前面のアプリ / ブラウザー」のままで構いません。
5. 「開始」を押し、5秒以内に演奏先の鍵盤画面をクリックしてください。
6. 待ち時間が終わった時点のウィンドウが入力先になります。
7. F8で停止します。別ウィンドウに切り替えても停止します。

【設定】
速度100%: 元のテンポ。50%: 半分の速さ。テンポ変更も読み取ります。
待ち時間: 開始ボタンを押してから入力開始までの秒数です。
移調: 半音単位。演奏先の転調は0を基準にしてください。
原音の長さで押す: MIDIのnote-on/note-offを基準にキーを押して離します。
短く押す: 各音を最大45msで離します。音切りの相性が悪い場合に試してください。
ペダル: MIDIのCC64をSpaceキーに変換します。演奏先のペダルキーがSpaceの場合に使います。
Roblox限定: Roblox Player以外が前面なら開始しないモードです。

【キー配置と制限】
標準61鍵のVirtual Piano配置に対応します。1=C2、t=C4、m=C7です。
キー配置が違うピアノでは音程が一致しません。本版にキー配列編集機能はありません。
範囲外の音はオクターブ単位で範囲内へ折り返します。
黒鍵はShiftを使用します。同じ物理キーの白鍵・黒鍵を同時に保持する和音などは、
演奏先の入力処理によって完全再現できません。音量差（velocity）も再現できません。
形式0/1の拍単位MIDIに対応。形式2・SMPTE時間軸は未対応。ドラムチャンネル10は除外します。
Windowsや演奏先の処理によるタイミング誤差があります。

【入力先について】
演奏前にIMEを英数にし、チャット・検索欄・メニューを閉じてください。
演奏中に同じブラウザー内でタブを変えたり、入力欄へカーソルを移すことは検出できません。
変更する前にF8で停止してください。別ウィンドウへ切り替えると停止します。
プログラムと演奏先を通常権限で起動してください。
演奏先が外部キー入力を受け付けない場合、このツールでは演奏できません。
署名のない自作EXEです。配布元の署名や第三者の認証は付いていません。

【フォルダー構成】
MIDIKeyboardPlayer.exe   Python不要の実行ファイル
source/                 Pythonソース、テスト、EXEの再ビルド手順
samples/demo.mid        このツール用に作成した8音の動作確認サンプル
個人利用MIDI/           以前使用した曲。公開・再配布する前に権利確認が必要
third_party_licenses/   EXEに含まれるPython / Tcl / Tkのライセンス等
公開について.txt         将来GitHub等へ公開するときの注意点
.gitignore              個人利用MIDIや生成物等をGitの追加対象から外す設定

【ソースから起動・ビルド】
Python 3.10以上で source/player.py を実行できます。実行時の追加ライブラリーは不要です。
source/build.bat を実行するとPyInstallerを取得してEXEを作ります（ネット接続が必要）。
source/requirements-build.txt にビルド用バージョンを固定しています。
samplesフォルダーはEXEと同じ場所に置いてください。
自動確認: python source/test_player.py
EXE内の確認: MIDIKeyboardPlayer.exe --self-test 結果.json
自動確認では実キー入力を送信しません。
